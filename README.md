# Blender workshop

Builds 3D items with Blender in a Claude Code cloud session.

- `.mcp.json` connects the cloud desktop's screen-control tool, so Claude can open Blender and use it by hand.
- `scripts/install-blender.sh` installs Blender.
- `scripts/open-blender.sh` opens Blender on the cloud desktop.
- `models/` holds `.blend` files; `exports/` holds STL/3MF/OBJ/GLB exports.
